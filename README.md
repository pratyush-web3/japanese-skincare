# Japanese Skincare Website

A modern Japanese skincare website built with Next.js, Tailwind CSS, Framer Motion, and Lucide Icons.

Inspired by Japanese minimal aesthetics, natural beauty, and luxury skincare brands.

---

# Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Responsive Design

---

# Features

- Japanese-inspired UI
- Smooth animations
- Modern responsive layout
- Minimal aesthetic design
- Privacy Policy page
- Terms & Conditions page
- SEO-friendly structure
- Soft Japanese color palette

# Getting Started

## Install dependencies

```bash
npm install
```

---

## Run development server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
